## AI Share-Specific URL Formats

These are easier to block or configure a warning in a proxy/firewall.

| AI         |  URL                                          |
| ---        | ---                                           |
| ChatGPT    | `https://chatgpt.com/share/{id}`              |
| Claude     | `https://claude.ai/share/{id}`                |
| Copilot    | `https://copilot.microsoft.com/shares/{id}`   |
| DeepSeek   | `https://chat.deepseek.com/share/{id}`        |
| Gemini     | `https://g.co/gemini/share/{id}`              |
| Grok       | `https://grok.com/share/{id}`                 |
| Manus      | `https://manus.im/share/{id}`                 |
| Meta AI    | `https://www.meta.ai/s/{id}`                  |
| Poe        | `https://poe.com/s/{id}`                      |
| Qwen       | `https://chat.qwen.ai/s/{id}`                 |
| T3 Chat    | `https://t3.chat/share/{id}`                  |                      

## AI Sharing / Chat URLs

In these cases the URLs to share are also the chat themselves, so warnings could conflict with sanctioned AI platforms.

| AI             |  URL                                             |
| ---            | ---                                              |
| Bolt           |  `https://bolt.new/~/{id}`                      |
| Character.AI   |  `https://character.ai/chat/{id}`               |
| HuggingChat    |  `https://hf.co/chat/r/{id}`                    |
| Phind          |  `https://www.phind.com/search?cache={id}`      |
| Lovable        |  `https://lovable.dev/projects/{id}`            |
| Mistral Le Chat|  `https://chat.mistral.ai/chat/{id}`            |
| NotebookLM     |  `https://notebooklm.google.com/notebook/{id}`  |
| Perplexity     |  `https://www.perplexity.ai/search/{id}`        |
| v0             |  `https://v0.app/chat/{id}`                     |
